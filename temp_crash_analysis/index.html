OPTIMIZATION 2. Damping Factor Optimization

Target: d > 0.90, Overall MRE ≤ 0.05

The central model improvement. We wanted to reduce the model's dependence on ground-truth GPS data (the teleportation vector) by increasing the damping factor above 0.90. A 576-combination parameter grid search failed entirely — no existing parameter could solve this.

The breakthrough: demand-weighted transitions. By adding a single parameter γ that weights transitions by average link popularity, the matrix learns structural traffic demand. With γ=0.20, d=0.96: the model uses only 4% ground truth but achieves better accuracy than the original at d=0.80 with 20%.

Validated with 3 independent train/test splits (temporal, day-of-week, 5-fold CV).

PREDICTION 4. Crash Prediction via Per-Link μ Control

Predicting crash-day traffic without crash-day data

The most technically detailed report. Documents the full journey from failed speed/lane/adjacency modifications to the discovery that μ (dwell-time) is the only effective control parameter for local disruption modeling.

At μ=20, the self-loop retains 99.5% of mass — no other parameter can overcome this. Reducing μ to 0.01 on the 21 I-15 SB links drops the 08:30 crash-corridor error from 179% to 11.5%, using only last week's data as input.

Includes per-frame analysis, two-population breakdown (diversion vs rebound), physics explanation, and honest limitations section.

ANALYSIS 5. Game Day Analysis: Utah vs #10 Washington

September 15, 2018 — Rice-Eccles Stadium, 47,445 attendance

A completely different type of event: a planned football game with documented road closures (500 South lane reduction, Guardsman Way full closure). Validates the model on a non-crash disruption with known spatial and temporal structure.

The model detects the full game-day cycle: pre-event closures (−85.9% on 500 South), arrival surge (+463.4%), and post-game departure (+247.9%). The μ-control prediction achieves 94–98% error reduction during closure phases.

VALIDATION 6. Learning the μ Profile: Cross-Validated Baseline

4 Tuesdays, 96 timeframes, leave-one-out CV

The reverse experiment: instead of knowing an event and tuning μ, we ask what μ the data itself suggests. On normal Tuesdays (no events), the optimal μ stays between 10 and 20 across all 96 time slots, with only 1% improvement over fixed μ=20.

The key discovery: prediction error correlates r = 0.9999 with the raw ground truth gap between Tuesdays. The model is 96.6% transparent — it adds less than 4% distortion to the input data. The error is in the week-to-week GPS variation, not the model.

This establishes the baseline: μ ≈ 20 on normal days, so any deviation signals a real disruption.

Key Parameters

Three parameters control the model's behavior:

ParameterSymbol DefaultRole
Damping factor d 0.96 96% matrix, 4% ground truth. Controls global accuracy vs data dependence.
Demand sensitivity γ 0.20 Weights transitions by average link popularity. Enables high d with low MRE.
Dwell-time scale μ 20 (global), 0.01 (disrupted links) Controls mass retention per link. The only effective knob for local disruption modeling.
