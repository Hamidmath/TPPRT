Key Findings

  • The demand-weighted model (d=0.96) detects game-day traffic anomalies at the stadium area, with deviations visible across all corridor categories
  • The μ-control mechanism allows prediction of event-day traffic using only the previous week's data as input
  • The model uses only 4% ground truth (d=0.96) yet captures event-driven traffic redistribution
  • Total analysis time: 63.7s on GPU
