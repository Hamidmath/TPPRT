# Documents

All written artefacts (papers, reports, slides, technical notes) live here.
The organisation is by *kind of document*, not by topic, so you know where to
put a new file without having to guess.

```
documents/
├── paper/                   Main publication draft
│   ├── main.tex
│   ├── references.bib
│   ├── main.pdf             (built)
│   └── figures/             Paper-only figures that are NOT regenerated
│                            by figures/paper/generate_figures.py
│
├── walkthrough/             Step-by-step pipeline description
│   ├── main.tex             (writing-in-progress companion to the paper)
│   └── main.pdf             (built)
│
├── notes/                   Short technical notes (one folder per note)
│   └── two_phase_pagerank_combined/
│       ├── two_phase_pagerank_combined.tex
│       └── two_phase_pagerank_combined.pdf
│
├── presentation/            Beamer slides
│   ├── slides.tex
│   ├── slides.pdf           (built)
│   └── figures/             Slide-only assets (e.g. fig_toy_network.png)
│
└── reports/                 Long-form markdown reports
    ├── algorithm.md
    ├── self_loop_report.md
    ├── smoothing_justification.md
    ├── traffic_events.md
    ├── issue_report/
    └── data/                JSON artefacts cited by reports and figures
        ├── smoothing_grid_search_results.json
        └── verification_results.json
```

## Figure resolution order

Both `paper/main.tex` and `presentation/slides.tex` use
`\graphicspath{{./figures/}{../../figures/paper/}}`, so an
`\includegraphics{fig_name}` search order is:

1. `./figures/` next to the `.tex` file (document-specific assets).
2. `../../figures/paper/` at the project root (regenerated by
   `figures/paper/generate_figures.py`).

Adding a new regenerable figure therefore requires no edit to the document's
preamble.

## Building

From the project root:

```
make paper          # documents/paper/main.pdf
make walkthrough    # documents/walkthrough/main.pdf
make slides         # documents/presentation/slides.pdf
make docs           # all of the above
```
